A single funny line for the
[Make the Judge Laugh in One Line](https://make.fun/c/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21)
competition on make.fun — a horoscope, a tall dark stranger, and a fridge at midnight.

## Run

Needs Node.js 22. No dependencies, no network access.

```sh
node main.ts
```

It writes one line to `/output/entry.txt`:

> My horoscope said I'd meet a tall, dark stranger tonight, so I'm standing in front of the fridge at midnight.
